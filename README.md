# Jgent downloads

This repository is the public distribution channel for Jgent. It intentionally
does not contain Jgent source code, internal documentation, infrastructure,
configuration, credentials, or development tooling.

Download the current Windows package from the [latest release](../../releases/latest).
Verify SHA256SUM.txt before extracting Jgent-win-x64.zip.

The application is proprietary software. See [LICENSE](LICENSE),
[THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt), and
[DATA-NOTICE.txt](DATA-NOTICE.txt). latest.json records the private source
commit used to build each published package.
